# Dossiers de Départ — Projets d'Imitation (Niveau N1)

Bienvenue sur le dépôt des **dossiers de départ**.

Ce dépôt contient le code source initial nécessaire pour commencer chaque session d'apprentissage (de la session **S2** à la session **S12**).

---

## 1. À quoi sert ce dépôt ?

* Dans chaque session, vous réalisez une nouvelle fonctionnalité de l'application (Blog Web).
* Le dossier `dossier-depart/` vous donne le code prêt et validé au début de la session.
* Il vous permet de démarrer immédiatement les tutoriels sans repartir de zéro.
* Si vous avez du retard sur une session précédente, vous pouvez reprendre directement le bon code ici.

---

## 2. Comment utiliser un dossier de départ ?

Suivez ces 4 étapes simples :

1. **Repérez votre session :** Ouvrez le dossier de votre session du jour (exemple : `S6/`).
2. **Trouvez le code :** Entrez dans le sous-dossier `dossier-depart/`.
3. **Copiez le dossier :** Copiez tous les fichiers dans votre propre dossier de projet personnel.
4. **Commencez à coder :** Ouvrez votre projet dans VS Code et suivez les instructions du tutoriel.

> **Règle importante :** Ne modifiez pas les fichiers directement dans ce dépôt. Faites toujours une copie dans votre propre dossier de travail.

---

| Session | Contenu du dossier de départ | Ce que vous allez apprendre |

## 4. Stack Technique Pure N1

Le code utilise strictement des technologies fondamentales simples :
* **HTML5** sémantique.
* **CSS3** natif pur (sans framework).
* **JavaScript** natif pur (Vanilla JS).
* **PHP** procédural modulaire.
* **MySQL** avec requêtes préparées via **PDO**.
